# Arrow conversions (TM, T, R families)

Converted arrows are built from the drawings' grid-inset dimensions. Straight arrows are exact polygons (per-vertex radii inscribed so the outline reaches the dimensioned extremes; several have tapered shafts that the arrow element cannot express). R2-14 is an exact path (curved shaft + head). R6-30 uses the arrow element (its inset dimensions the head to the sharp corners, the element's convention). Open-chevron parking arrows are polygons. Each converted spec keeps its `symbols` desc entry and carries a note describing the construction. All overlays checked against the traced artwork.
