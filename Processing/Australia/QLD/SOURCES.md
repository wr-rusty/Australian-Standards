# Sources — Queensland (TMR)

* `Original PDFs/TC signs/` — TMR "TC signs full collection" (June 2026), the officially approved non-standard traffic
  control signs, one A4 design sheet per sign in category folders, plus TMR's index. Downloaded from
  https://www.tmr.qld.gov.au/business-industry/Technical-standards-publications/TC-signs (updated quarterly; the site
  refuses scripted downloads, so the ZIP was fetched through the Browser pane).
* `Original PDFs/q-series.pdf` — MUTCD Q-series signs (Queensland-specific signs in Part 1 of the Queensland MUTCD); not yet extracted.
* `Original PDFs/qld-mutcd-part-1.pdf`, `amendments.pdf` — Queensland MUTCD Part 1 (sign illustrations) and the TC signs amendment list.
* Licence: Queensland Government publications are under Creative Commons Attribution 4.0 unless stated otherwise on the
  document; the TC sign sheets carry no separate restriction. Attribute "© State of Queensland (Department of Transport and Main Roads)".

`SVGs/` is produced by `tools/qld_extract.py` (see `tools/README.md`); `SVGs/MANIFEST.csv` records the size source
and anything to check. Superseded sheets, the index, logo sheets and the signing/pavement layout sheets are skipped.

## Generated set (`SVGs (generated)/`)

Built spec-driven from 2026-09-09 (SGN-003), the way the NSW rebuild is done: one spec per sheet in `tools/specs/QLD/<CODE>.json`
(top-level `"pack": "QLD"`, `"drawing"` naming the sheet where the sign's code differs from the PNG name, e.g. the two plates of
RM9-Q01 are `RM9-Q01-A` / `RM9-Q01-B` with `"which"`), every dimension read from the sheet's lettered size table (rendered
upright at 200 dpi into `Original PNGs/<CODE>.png` by a scratch pymupdf pass — TC sheets by code with `_p2`… for later pages,
Q-series book pages by the code in the title block; only the regulatory family is rendered so far), generated by `tools/signgen.py`
into `SVGs (generated)/<family>/` with `MANIFEST.csv`. Reading conventions (recorded in every spec's notes): the sheet's `c` is the
white edge and `d` the edge + border (10/30, 15/45, 5/15 as the national 10/20, 15/30, 5/10); where a sheet tables several sizes
the size A is generated unless the sign is a companion to a national sign, in which case the size matching that sign's illustrated
width (e.g. 600 for plates under R4-1 / R6-10); the sheets give no letter widths, so word gaps were measured from the sheets' live
text and drawings; AS 1744 (plus0) spacing, `DM` / `EM` / `CM` read as the plain series. Symbols traced from the sheets into
`tools/symbols/qld_*.svg` (trams, car, motorcycle, caravan, skaters, e-scooter, lane-filtering scene, pedestrian, arrows); the
W8-3 arrow and R1-2 give-way geometry reused from AS 1743 where the sheet refers to them. Overlay-checked with
`tools/compare_drawing.py` (specs carry `panel_px` where needed). Skips (non-signs, LED signs, sheets that cannot be read) are
manifest rows with the reason. Attribution as for the sheets: © State of Queensland (Department of Transport and Main Roads), CC BY 4.0.
